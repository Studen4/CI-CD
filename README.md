# 🛠 Лабораторна робота: Основи роботи з Git

## 📋 Мета роботи
Освоєння базових навичок роботи з системою контролю версій **Git** та взаємодії з віддаленими репозиторіями.

---

## ✅ Зміст заняття (Пункти завдань)

Ця робота складається з наступних ключових етапів:

1.  **Встановлення та налаштування Git.**
    * Встановлення Git на локальну машину.
    * Початкове налаштування користувача (`git config`).

2.  **Основні команди роботи з Git.**
    * Створення локального репозиторію (`git init`).
    * Відстеження змін (`git add`, `git commit`).
    * Перегляд стану та історії (`git status`, `git log`).

3.  **Робота з віддаленими гілками.**
    * Прив'язка до віддаленого репозиторію (`git remote add`).
    * Завантаження локальних змін (`git push`).
    * Отримання змін з віддаленого репозиторію (`git pull`, `git fetch`).

4.  **Вирішення конфліктів.**
    * Створення сценарію конфлікту.
    * Локальне вирішення конфліктів при злитті гілок (`git merge`) або оновленні коду (`git pull`).
